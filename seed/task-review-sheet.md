# Delivery Hero — Task Pool Review Sheet

> Companion to `seed/delivery-hero-seed.json` · Drafted with Claude for admin review · 23 September 2026

## How to review

Two admins review every task independently (DEC-40). For each one, check:

1. **Ten-second test.** Can you pick the answer within about 10 seconds, and is it clearly the single best answer? If not, suggest a rewrite or cut it.
2. **Fair for everyone.** Could a developer, tester, business analyst or manager reasonably answer it? It should test judgment, not trivia.
3. **Tone.** Playful, never mean, and no real colleagues, clients or company names.
4. **Fits the phone.** Short prompt; the time limit feels right.

Tick R1 or R2 when a task passes, or write a note. The owner applies agreed changes to the seed file and reruns `python3 tools/validate_seed.py seed/delivery-hero-seed.json`, which must report 0 errors. Content freeze is Friday 16 October (Charter section 12).

Options are shown to every player in exactly the order below; nothing is shuffled (DEC-20). Correct answers are spread evenly across positions A–D and never sit in the same position twice in a row.
