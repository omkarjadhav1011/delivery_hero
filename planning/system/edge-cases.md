# Edge cases

How the unified planning system detects and handles each situation. "Test" names the case in `planning/scripts/tests/test_planning.py`. Rows marked "procedure" are handled by the `/dh` instructions (`.claude/skills/dh/reference.md`) on top of the scripted detection.

| # | Scenario | Detected by | Response | Handled in | Test |
|---|---|---|---|---|---|
| 1 | Interruption mid-task | Journal active with a task in progress | Resume protocol: compare with Git, rerun the task's test, continue from the next action | `journal.py check`, `state.py` state 3, `/dh resume` | `TestJournal.test_interrupted_session_resume_lines_and_checks` |
| 2 | Interruption mid-commit | `.git/index.lock` left behind; or HEAD moved past the journal's last commit | State 1 stops and tells the owner how to clear the lock; a landed commit is reported so the task is checked, not redone | `state.py` preflight, `journal.py check` | `TestState.test_preflight_merge_rebase_lock_detached_and_missing_tools`, `TestJournal.test_commit_after_journal_is_reported` |
| 3 | Interruption mid-test | Journal's failing tests or task in progress | Rerun the failing or last test before anything else | `journal.py check` ("Rerun first") | `TestJournal.test_attempt_budget` |
| 4 | Context compaction or `/clear` mid-session | SessionStart fires with `compact` or `clear` | The hook prints up to 3 resume lines; `/dh` resumes from the journal, not the conversation | `session_start.py`, `journal.py hook-lines` | `TestSessionStartHook.test_hook_prints_resume_lines` |
| 5 | An API error or rate limit ends a turn | Same as an interruption: the journal is still active | Next session or turn: resume protocol | journal, procedure | covered by 1 |
| 6 | Dirty working tree with unknown changes | `journal.py check` lists uncommitted files; files already uncommitted when the session started are recorded and reported separately; with no session, `check` asks what they are | Show the files and ask; never discard without approval | `journal.py check`, `state.py` | `TestJournal.test_interrupted_session_resume_lines_and_checks`, `TestJournal.test_files_dirty_before_the_session_are_not_blamed_on_it` |
| 7 | Branch or last commit differs from the journal | `journal.py check` | Show the difference and ask before continuing | `journal.py check`, hook line 3 | same |
| 8 | Merge conflict or rebase in progress | `MERGE_HEAD`, `rebase-merge/`, `rebase-apply/`, unmerged paths | State 1: explain and stop; the owner finishes or aborts | `state.py` preflight | `TestState.test_preflight_merge_rebase_lock_detached_and_missing_tools` |
| 9 | Detached HEAD | `git rev-parse --abbrev-ref HEAD` is `HEAD` | State 1: switch to a branch first | `state.py` | same |
| 10 | Two sessions or worktrees claim the same subplan | Atomic claim file in Git's common directory; active journals across `git worktree list` | The second `start` exits 3; `next.py` marks the subplan claimed | `journal.py`, `next.py`, `validate.py` | `TestJournal.test_two_sessions_cant_claim_the_same_subplan` |
| 11 | Stale claim (over 24 hours without journal activity) | Claim's `updated` time | Warn; release only with the owner's approval (`release --force`) | `journal.py`, `validate.py` | `TestJournal.test_stale_claim` |
| 12 | Documents changed after planning | SHA-256 manifest (line endings ignored) | State 4: subagents read the changed documents in full, impact analysis, proposed plan changes; `--update` only after that | `docs_manifest.py`, `state.py` | `TestManifest`, `TestState.test_changed_documents_after_planning` |
| 13 | Malformed subplan or ledger input | Field, section, status, task and log syntax; override classification | State 5: show the errors and propose fixes | `validate.py`, `trace.py` | `TestValidate.test_malformed_subplan`, `TestTrace.test_cut_needs_an_approved_override` |
| 14 | Malformed journal | `journal.py` parse | Hook and state 3 say so; fix by hand or `end --outcome paused` after comparing with Git | `journal.py`, `validate.py` | `TestJournal.test_malformed_journal` |
| 15 | Dependency cycle or missing dependency | Graph search | State 5 | `validate.py` | `TestValidate.test_dependency_cycle` |
| 16 | Missing tool: Docker, Node.js, Python or the GitHub CLI | `shutil.which`, `docker info` | Git or Node missing: stop. Docker missing: unit tests only, integration and end-to-end tests pending. `gh` missing: skip state 7 and PR checks. Python missing: `run.mjs` exits 127 and the hooks fail closed | `state.py`, `run.mjs`, `run-hook.mjs` | `TestState.test_preflight_merge_rebase_lock_detached_and_missing_tools` |
| 17 | Failing hooks | Self-test: force push must exit 2, `npm run lint` must exit 0 | State 1: stop, because nothing protects the session | `state.py` preflight | run in Step 3 verification |
| 18 | CI red on `main` | `gh run list --branch main --workflow ci.yml` | State 7: offer to fix it first | `state.py` | `TestState.test_ci_red_on_main_and_changes_requested` |
| 19 | Blocked owner action | `Depends on` names an OA that isn't Done; overdue OA | Not eligible, with the reason; overdue actions flagged in STATUS.md; owner checklist first in `/dh` | `next.py`, `status.py` | `TestNext.test_order_dependencies_owner_actions_and_questions`, `TestStatusAndCheckpoints.test_overdue_owner_action_and_milestone` |
| 20 | Open question blocking a task | `Depends on` names an unanswered Q; a `[Blocked: ...]` task | Not eligible; listed as a blocker | `next.py`, `status.py` | `TestNext.test_order_dependencies_owner_actions_and_questions`, `TestNext.test_blocked_task_and_in_progress_first` |
| 21 | A test fails past the attempt budget | Third failed `journal.py attempt` exits 4 | Stop; mark the task Blocked with evidence; propose options; ask | `journal.py`, `/next` | `TestJournal.test_attempt_budget` |
| 22 | A story is cut mid-sprint | Subplan status Cut | Needs an approved Cut override (date, "approved", document 04 cut order); `next.py` skips it | `trace.py`, `next.py` | `TestTrace.test_cut_needs_an_approved_override` |
| 23 | A request outside the plan | Procedure: the request cites no subplan task | Proposed plan change (section 13 of the conventions) or an open question; never unplanned work | `/dh` reference, procedure | — |
| 24 | A milestone date passed | Charter milestones against today; checkpoint rules | STATUS.md milestone "passed"; state 6 for unrecorded checkpoints | `status.py`, `state.py` | `TestStatusAndCheckpoints.test_overdue_owner_action_and_milestone`, `TestState.test_checkpoint_and_freezes` |
| 25 | Checkpoint rule triggers | CP-S0 capacity numbers, CP-S1 unfinished Must stories | State 6: numbers, proposed cuts per document 04's cut order, owner decides; decision recorded in `checkpoints.md` | `status.py`, `state.py` | `TestStatusAndCheckpoints.test_status_file_and_capacity_rule`, `TestState.test_checkpoint_and_freezes` |
| 26 | Content freeze (from Fri 16 Oct) | Date | Only hardening and event subplans eligible; task content edits only fix errors | `_common.freeze_state`, `next.py` | `TestDates.test_freeze_windows` |
| 27 | Deployment freeze (from Tue 20 Oct) | Date | Only event-phase work; merges only for event-stopping problems | `next.py`, `state.py` | `TestNext.test_freeze_and_could_rules` |
| 28 | Deploy lock during the event | Event day | State 6 note: no merges; the deploy lock must show the game in progress; `/dh` never weakens the lock or the deploy script | `state.py`, `CLAUDE.md` rules | `TestState.test_checkpoint_and_freezes` |
| 29 | A PR review requests changes | `gh pr list` review decision `CHANGES_REQUESTED` | State 8 lists it first: address the review before new work | `state.py` | `TestState.test_ci_red_on_main_and_changes_requested` |
| 30 | The PRD and stories disagree | A feature or epic with no story; a cited ID no document defines | Ledger gap marked as a doc issue; raise with the owner; record in `doc-issues.md` | `trace.py`, `ids.py` | `TestTrace.test_feature_without_story_is_a_doc_issue`, `TestTrace.test_unknown_citation_task_without_id_and_double_ownership` |
| 31 | An ID in two subplans | Two non-shared citations | Problem: mark all but one `(shared)` | `trace.py` | `TestTrace.test_unknown_citation_task_without_id_and_double_ownership` |
| 32 | No plan yet | No subplans | State 2: the planning flow; scripts exit 2 | `state.py` and every script | `TestNoPlan.test_no_plan_state_and_exit_codes` |
| 33 | Windows paths and line endings | Backslash paths; CRLF checkouts | Paths normalized; hashes ignore line endings; `run.mjs` finds `py -3` or `python` when `python3` is the Store placeholder | `_common.py`, `docs_manifest.py`, `run.mjs` | `TestWindowsPaths`, `TestManifest.test_line_endings_dont_count_as_changes` |
| 34 | On `main` | Branch name | Note in the state; the hooks block commits on `main` | `state.py`, `guard_bash.py` | — |
| 35 | Deploy stopped with exit code 75 (a game is in progress) | `probe.py deploy` reads the Deploy run and its log | Nothing was restarted and the game continues; re-run the job after Results or Closed (document 16, section 10.2); the subplan stays In review | `probe.py`, `/dh` reference (Deploy verification) | `TestDeployResults.test_exit_codes` |
| 36 | Deploy failed and rolled back (exit 1) | Same | The previous release is running; read the backend logs, fix on a `fix/` branch, merge again (document 16, section 12) | `probe.py`, `/dh` reference | `TestDeployResults.test_exit_codes` |
| 37 | Deploy failed before deploying (build or tests) | Same | Treated like CI red on `main`: fix first | `probe.py`, state 7 | `TestDeployResults.test_exit_codes` |
| 38 | `/health` failing or slow after a deploy | `probe.py health` (HTTP status, `UP`, under 1,000 ms for NFR-08) | Check the deploy result, then the troubleshooting table (document 16, section 12); the subplan isn't Verified in production | `probe.py`, `trace.py` | `TestProbe.test_health_headers_and_record` |
| 39 | The Oracle instance stopped | DNS resolves but `/health` and port 443 are unreachable (probe result "couldn't check") | Owner checklist: start it in the console, then recheck (document 16, section 14) | `probe.py`, `/dh` reference (Production problems) | `TestProbe.test_health_headers_and_record` (unreachable case) |
| 40 | The certificate close to expiry | `probe.py cert`: fewer than 14 days left (document 16, section 11.1) | Owner checklist: `scripts/renew-cert.sh`, check `journalctl -t dh-certs` (section 11.3) | `probe.py` | `TestProbe.test_certificate_days_left` |
| 41 | DNS doesn't point at the machine | `probe.py dns` against the public IP in `environment.md` | Owner checklist: fix the DuckDNS record (document 16, section 6.4) | `probe.py`, `owner.py verify` | `TestOwner.test_source_section_and_verify_without_a_domain` |
| 42 | Owner actions due or overdue | `owner.py` | State 8: owner-checklist mode, one item at a time, before new work | `owner.py`, `state.py` | `TestOwner.test_state_8_owner_actions_due`, `TestOwner.test_classify_next_and_record` |
| 43 | A date-bound subplan before its phase (trial, hardening, freeze, event, after) | `next.py` against the phase windows | Not eligible, with the start date | `next.py` | `TestDateBoundSubplans.test_trial_event_and_after` |
| 44 | Trial run no-go | CP-T recorded as no-go in `checkpoints.md` | Fix subplans in H from the triaged defects; the re-check on Mon 19 Oct (CP-H); if that fails, propose moving the event date (A-01@01) | `status.py`, `state.py`, `phase.py` | `TestStatusAndCheckpoints`, `TestPhases.test_checkpoints_and_milestones` |
| 45 | Load test failure | LT-01 Fail in `check-results.md`; go/no-go criterion 2 not met | Performance fix subplans, then rerun LT-01 (document 15, section 18: "and after performance fixes"); the trial's entry criteria aren't met until it passes | `status.py` (Testing due, Go/no-go) | `TestStatusAndCheckpoints.test_overdue_owner_action_and_milestone` |
| 46 | Event-day incidents | Event day: phase E, state 6 is primary | Runbook mode: document 16, sections 11.1 and 12 to 14 (hotspot, start the instance, rollback, postpone); no code changes or merges; incidents noted for the retrospective | `phase.py`, `/dh` reference (Event) | `TestPhases.test_rules_in_force`, `TestState.test_checkpoint_and_freezes` |
| 47 | The owner is unavailable | Nothing moves without approvals; overdue items accumulate | Nothing merges, deploys or edits `docs/`; on return, `/dh` lists what's overdue with numbers and proposes catch-up or cuts | `status.py`, `owner.py`, `state.py` | covered by 19, 24 and 42 |
| 48 | A subplan ID that looks like a document ID | Phase prefixes FZ and AE, not F and A | `F-01` stays a PRD feature and `A-01` an admin screen | `_common.py` | `TestDateBoundSubplans.test_phase_ids_dont_clash_with_document_ids` |
| 49 | Testing a phase on another date | `DH_TODAY=YYYY-MM-DD` | Every script and the session-start hook use that date | `_common.today`, `session_start.py` | `TestPhases.test_every_phase_through_dh_today`, `TestDhTodayEverywhere` |
